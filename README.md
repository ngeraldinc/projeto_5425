Projeto Final - 5425

A minha ideia é criar um sistema de agendamento de marcações. Quando o sistema detetar que um cliente faltou a duas marcações anteriores, não deverá permitir que agende uma nova. Nesse caso, o cliente deverá contactar o atendimento, por exemplo, através do WhatsApp.
O sistema deverá rejeitar o pedido de agendamento com base no histórico do cliente, que deve incluir o nome, o número de telefone, o e-mail e o registo das marcações concluídas e das faltas.

Esta ideia baseia-se no meu trabalho atual, onde utilizamos a aplicação Zappy para gerir a agenda. No entanto, a aplicação ainda não tem esta funcionalidade, pelo que o administrador tem de controlar as faltas manualmente.

O meu objetivo seria criar especificamente essa funcionalidade, e não desenvolver a aplicação toda.
